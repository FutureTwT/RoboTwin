# 001_bottle 碰撞模型与视觉模型大小对比

本文记录 `assets/objects/001_bottle` 中碰撞 GLB 与视觉 GLB 的尺寸对比。

## 测量对象

该目录中共有 23 组模型：

- 视觉模型：`assets/objects/001_bottle/visual/base*.glb`
- 碰撞模型：`assets/objects/001_bottle/collision/base*.glb`
- 缩放参数：对应的 `assets/objects/001_bottle/model_data*.json` 中的 `scale`

每一组编号相同的文件互相对应，例如 `visual/base13.glb` 对应 `collision/base13.glb`。

## 测量口径

使用 `trimesh` 读取 GLB 中的全部 mesh 顶点，计算模型在局部坐标下的 AABB 尺寸，也就是外接包围盒尺寸。

这些 GLB 都不是 watertight 闭合网格，因此不能可靠计算真实实体体积。本文中的“体积比例”指 AABB 包围盒体积比例：

```text
碰撞包围盒体积比例 = collision AABB volume / visual AABB volume
```

场景尺寸需要再乘以 `model_data*.json` 中的 `scale`。例如 `base13` 的 `scale` 为 `0.132`。

## 总体结论

`001_bottle` 的碰撞模型整体比视觉模型略大，并且基本包住视觉模型。

- 碰撞包围盒体积平均是视觉包围盒的 `1.123x`
- 最小比例出现在 `base19`，为 `1.066x`
- 最大比例出现在 `base10`，为 `1.149x`
- 单轴平均放大比例约为：
  - X 方向：`1.052x`
  - Y 方向：`1.018x`
  - Z 方向：`1.050x`

也就是说，碰撞模型主要在 X/Z 水平方向外扩，大约多出 3% 到 6%；Y 方向外扩较少，大约多出 1.6% 到 1.8%。

- 原始视觉 AABB 尺寸：`[0.489092, 1.84739, 0.481216]`
