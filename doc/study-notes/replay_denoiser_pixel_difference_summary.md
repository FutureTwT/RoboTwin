# Replay 去噪器像素差异记录

## 问题与结论

| 问题 | 结论 |
| --- | --- |
| OIDN 多次 replay 是否存在像素差异？ | 同一台机器没有差异，同一台机器使用不同显卡也没有差异；跨机器存在差异。 |
| OptiX 多次 replay 是否存在像素差异？ | 同一台机器没有差异，同一台机器使用不同显卡也没有差异；跨机器存在差异。 |
| OIDN 与 OptiX 的 replay 是否存在像素差异？ | 在同一台机器上也存在像素差异。 |
| CYP 数据与当前 replay 子集是否完全一致？ | 不一致。CYP 数据与 PRO 6000、L40 上生成的 replay 数据均存在像素差异。 |

注意：OIDN 和 OptiX 各自进行内部比较时，结论相同：同一台机器没有像素差异，同一台机器使用不同显卡也没有像素差异，跨机器存在像素差异。
